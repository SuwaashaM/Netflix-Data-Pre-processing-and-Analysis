# 🎬 Netflix Movie Popularity Analysis

## 📖 Overview
This project analyzes a Netflix movie dataset to explore trends in **popularity, voting patterns**, and **release years**.  
The goal is to identify the **most and least popular movies**, the **most common genres**, and the **year with the highest number of releases**.

---

## 🧰 Tools & Libraries Used
- Python 3 (ipykernel)  
- Pandas – Data handling and cleaning  
- NumPy – Numerical operations  
- Matplotlib & Seaborn – Data visualization  
- JupyterLab – Code execution environment  

---

## 🧹 Data Cleaning & Preparation
- Checked and removed duplicate entries (`df.duplicated().sum() = 0`)  
- Converted data types for accurate analysis:  
  - `Vote_Count` → Integer  
  - `Vote_Average` → Float  
  - `Release_Date` → Year (Datetime conversion)  
- Verified descriptive statistics for all numeric columns  

---

## 📊 Summary Insights
1. **Drama** is the most common genre.  
2. Most movies have an **average vote rating**.  
3. **Spider-Man** is the most popular movie, while **The United States vs Billie** is the least popular.  
4. A majority of movies were released around **2020**, showing the dataset is focused on recent years.
